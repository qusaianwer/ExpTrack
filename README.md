 # ExpTrack

A personal expense tracker for Windows with a modern dark-themed desktop interface, built with Python.

## Features
- Dashboard with a quick overview of income, expenses, and balance
- Add, edit, and delete income and expense transactions
- Search and filter transactions by date
- Monthly budgets per category
- Statistics with pie and bar charts
- Export transactions to CSV
- Local storage with SQLite (your data stays on your computer)
- Command-line version included (mainl.py)

## Tech Stack
- Python
- CustomTkinter (GUI)
- SQLite
- Matplotlib (charts)

## Run
```bash
pip install customtkinter matplotlib
python gui.py
```
